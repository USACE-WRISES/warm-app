# The WARM mark

`warm-icon.svg`: a stream meander (white) under a riparian leaf (#8fd19e) on the WRISES apps' blue
tile (#41669f), the house shape CEICA's mark uses. The app draws the same mark in its header
(`web/src/lib/icons.ts`) and serves this file as its icon (`web/page/icons/warm-icon.svg`).

# Changelog

## v1.0.0 (2026-11-05)

- Replaces the R Shiny app, WARM 1.2.2, at wrises.shinyapps.io/warm
- A static web app that runs in the browser, hosted on GitHub Pages
- Find a model: criteria ranking and keyword search on one page
- Nine calculators in a compact layout, with live checks and suitability curves
- Many sites: a grid that takes pasted blocks and CSV files
- Save and reopen inputs; copy, download as CSV or print the results
- Fixes Lower Willamette's salmonid models and curves, per its 2014 report
- Fixes Upper Mississippi's canopy and forest type curves
- Fixes the Allen (1986) mink HSI and its large-wetland cover index
- Checked against the Shiny app's R code, ecorest and the ERDC note's tests
